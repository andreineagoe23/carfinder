    How it works

    1. Pick the car and your limits on the left. The links above update as you type.
    2. Search & show cars runs a GitHub Action that reads AutoScout24 and Kleinanzeigen and brings the matches back here, scored and de-duplicated. Takes about a minute.
    3. mobile.de blocks automated reading, so use its link above.
    4. Saved searches are re-checked twice a day; new cars get a NEW badge.

    First time? Open Settings and add a GitHub token so the site can start searches.

    Personal tool. Not affiliated with mobile.de, AutoScout24 or Kleinanzeigen. Prices and import costs are estimates — always check the car in person.

How it works

  1. Pick a make, and a model or All models, then set your limits. The links above update as you type.
  2. Search & show cars runs a GitHub Action that reads AutoScout24, Kleinanzeigen (🇩🇪) and Autovit (🇷🇴) and brings the matches back here, scored and de-duplicated. Takes about a minute.
  3. mobile.de, OLX, Publi24 and AutoUncle don't allow automated reading, so use their links above.
  4. Run the same search again later and cars that appeared since get a NEW badge.

First time? Open Settings and add a GitHub token so the site can start searches.

Personal tool, not affiliated with any of these sites. Prices are as listed; lei prices are converted at the day's ECB rate. Always check the car and its history in person.
